ASSESSMENT & OUTCOME-BASED EDUCATION

Rubric Manual 2026–27

ADYPSOE – Rubric Manual for Outcome-Based Assessment of Student Performance (Academic Year 2026–27).

Reference document for faculty on the design and application of analytic rubrics across assessment tools under the OBE framework. The described manual includes a common four-level analytic scale, guidelines for use, Bloom’s Taxonomy-to-assessment-tool mapping, assessment rubrics, score computation and a summary annexure.

The manual is identified as an institutional document issued by the Accreditation and OBE Cell with IQAC approval.

The PDF file has not yet been published in this website repository. The download link will be enabled after the approved file is uploaded and public access is verified.

Bloom’s Taxonomy – Question-Framing Chart

Reference chart for question-paper setting across revised taxonomy levels L1–L6, including cognitive focus, action verbs and question stems/examples. Classify a question according to the cognitive process actually required, not the action verb alone.

The approved chart file has not yet been published in this website repository. A download link will be added after the file is uploaded and verified.

IMPORTANT

Document control and applicability

  • Always check the programme, admission batch, semester and academic year to which a document applies.
  • These web pages provide guidance and summaries; the approved regulations, examination manual, official circulars and competent-authority decisions prevail in case of any difference.
  • Do not rely on an old locally saved copy when a revised version or official notice has been issued.
  • Confidential examination material, question papers, student marksheets and restricted institutional records will not be hosted on this public portal.

For a document that is not listed, contact the Examination Section through the official institutional channel.
